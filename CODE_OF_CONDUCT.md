# Code of Conduct

## Our Goal
This is a personal homelab repository meant for sharing ideas, learning Ansible, and helping each other build cool infrastructure.

## Expectations
* **Be respectful and constructive:** Whether opening an issue, submitting a PR, or discussing architecture, keep feedback polite and helpful.
* **Zero tolerance:** Harassment, hate speech, trolling, or aggressive behavior will not be tolerated and will result in issues/PRs being closed.
