# Services Overview

After building the rack, setting up the OS, and configuring all the Ansible automation, we are finally at the services—the stuff we actually get to use.

Let's start with probably the most simple tool here: the dashboard!

I just use it to list all the deployed services, keep shortcuts to frequently used websites, and... to be honest, nothing more. It’s simply the visual command center for the whole server.

Generally, almost any dashboard software would work here without problems and do basically the same thing. In my case, I have tried both Homepage and Glance, but currently, I am running **Homepage**.
